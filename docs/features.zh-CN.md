# Tabgent 使用指南

[← 首页](../README.zh-CN.md) · [English](features.md) · **简体中文**

从你正在使用的网页开始，告诉 Tabgent 你想解决的问题。下面通过食谱、出游、PDF 和网站搜索等示例，介绍具体用法。

## 按家里的人数调整食谱

食谱能做十二张煎饼，但你只需要六张。让助手换算用量，把步骤整理得更容易照着做。

来源：[Good Food — Easy pancakes](https://www.bbcgoodfood.com/recipes/easy-pancakes)

![按家里的人数调整食谱](assets/zh-CN/cooking.png)

可以这样问：

> 我只想做6张煎饼。请根据这份食谱把材料用量减半，整理一份简短的材料清单、制作步骤和所需时间。只根据当前食谱，用中文简洁回答。

打开食谱后直接提问，也可以先选中材料表。需要换算单位或列购物清单时，继续补充要求即可。

## 安排一次出游

把两家博物馆官网打开，告诉助手孩子的年龄和你关心的条件，请它比较门票、预约要求和适合孩子的活动。

来源：[V&A South Kensington](https://www.vam.ac.uk/south-kensington/visit) · [Young V&A](https://www.vam.ac.uk/young)

![安排一次出游](assets/zh-CN/travel.png)

可以这样问：

> 想带7岁的孩子在伦敦玩一天，正在考虑 V&A South Kensington 和 Young V&A。请阅读已打开的官方页面，比较是否免费、是否需要预约以及适合孩子的活动，只比较这三项，给出建议并附参观信息链接。不要预订。用中文简洁回答。

把官网放在同一个浏览器窗口，选择 Current window（当前窗口）。出行前再次确认最新信息；这个例子不进行预约。

## 使用 PDF

看不懂论文里的架构图？可以让助手结合原文解释，并把关键段落高亮留在文档里。

来源：Vaswani 等人，《[Attention Is All You Need](https://arxiv.org/abs/1706.03762)》，第 3 页图 1。

![使用 PDF](assets/zh-CN/pdf.png)

可以这样问：

> 请阅读这篇论文第 3 页和图 1，用中文通俗解释编码器、解码器各做什么，为什么解码器要使用掩码注意力。高亮第 3 页选中的原文，回答简洁一些。

选中 PDF 文字后提问，助手能结合页码定位。用 Tabgent 工具条的 **高亮**、**评论** 或 **询问 AI** 标记的原文会保存到[阅读笔记](#划线提问保存阅读笔记)；用阅读器自带标注工具添加的高亮、批注和修改只保存在下载的副本中，完成标注后，请使用阅读器的下载按钮保存。图片扫描件可能无法准确选中文字；PDF 无法打开时，可以切换到 Chrome 阅读器，但精确高亮需要 Tabgent 的 PDF 阅读器。在 Mac 上双击打开的 PDF，开启文件访问后也会使用 Tabgent 的 PDF 阅读器（见[在 Chrome 中打开的文件](#划线提问保存阅读笔记)）；也可以从资料库打开。上传附件可以用于阅读，但不会自动打开标注阅读器。论文版权归原作者所有。

### 点击引用查看原文

PDF 链接可以携带页码和原文片段。在 Tabgent 中打开后，会定位文字并显示临时搜索高亮：

```text
https://example.com/paper.pdf#page=3&search=ENCODED_TEXT&phrase=true
```

将 `ENCODED_TEXT` 替换为经过 `encodeURIComponent` 编码的原文，原网址的查询参数保留在 `#` 前。页码指定查找的起始位置，不会把搜索限定在这一页。这不会写入永久标注；没有可搜索文字的扫描件可能无法匹配。

## 读懂网页里的说明

软件出了问题，帮助文档又很长。这个例子让助手解释 Zotero 的文献同步与附件同步，并给出排查步骤。

来源：[Zotero — Syncing](https://www.zotero.org/support/sync)

![读懂网页里的说明](assets/zh-CN/read.png)

可以这样问：

> 我在两台电脑上用 Zotero，但第二台电脑没有 PDF。请阅读这份官方文档：数据同步与文件同步有什么区别，300 MB 限额会限制我的文献条目吗？用中文简洁解释，给我三个排查步骤。

## 对比不同方案

选方案时，价格之外还有使用条件。这里比较研究小组共享 1 GB PDF 时，Zotero Storage 与 WebDAV 是否适合。

来源：[Zotero Storage](https://www.zotero.org/storage) · [Syncing](https://www.zotero.org/support/sync)

![对比不同方案](assets/zh-CN/compare.png)

可以这样问：

> 阅读已打开的两份 Zotero 官方页面。我需要和研究小组共享 1 GB 的 PDF。用小表格比较 Zotero Storage 与 WebDAV：是否支持群组文件、空间由谁提供、相关费用。仅根据这两个页面给出建议，不要购买。用中文简洁回答。

## 让助手操作网站搜索

知道搜索条件，却不想逐项设置？把标题关键词和年份交给助手，让它操作 arXiv 的高级搜索，找到对应论文。

来源：[arXiv Advanced Search](https://arxiv.org/search/advanced)

![让助手操作网站搜索](assets/zh-CN/act.png)

可以这样问：

> 请操作这个 arXiv 搜索表单，查找 2020 年标题包含 Retrieval-Augmented Generation 的原始论文。设置标题字段和年份，然后执行搜索。用中文简短给出匹配的标题和链接，不要使用其他搜索服务。

## 划线、提问，保存阅读笔记

阅读网页、PDF 和 EPUB 电子书时，Tabgent 会把你的高亮和讨论保存为 Mac 上的 Markdown 文件。下次重读，或者在读另一篇文档时提问，都可以在这些记录的基础上继续。

**高亮一段原文。** 在网页、在 Chrome 中打开的本地文件、Tabgent 的 PDF 阅读器、EPUB 阅读器，或剪藏与订阅的阅读视图中选中文字，选区旁会出现一个小工具条：

- **高亮**：保存这段原文，并用柔和的黄色标出。
- **评论**：在选区旁打开编辑器。保存时，高亮和评论一起写入。取消或按 Esc 不会保存；评论为空也不会保存。
- **询问 AI**：保存这段原文，同时打开侧边栏、附上引用，开始一段关于这条高亮的对话。输入问题后可以继续追问。

工具条获得焦点时，方向键在这三个按钮之间移动。在评论编辑器里，⌘ Enter（Ctrl+Enter）保存，Esc 取消；输入法组字时这两个键都不会触发。

点击已高亮的文字，可以选择 **询问 AI** 或 **查看讨论**、**评论** 或 **编辑评论**，以及 **删除**。这段文字已有评论时，评论会显示在这些操作上方。即使 Codex 未连接，高亮和评论也能保存；重新打开网页、PDF 或书时，它们会自动恢复。

**评论一段原文。** 在选区工具条上选择 **评论**，或点击已高亮的文字后选择 **评论**。按 ⌘ Enter 或点击 **保存评论** 保存，按 Esc 取消。已有评论时，保存空评论会删除它；新选区上的空评论不会保存。之后再点击这段文字，评论会显示在操作按钮上方，选择 **编辑评论** 可以修改。侧边栏 **Page chats（网页会话）** 中的高亮列表和 EPUB 阅读器的高亮列表也会显示评论，并且可以在侧边栏列表中添加或编辑。和高亮一样，保存评论不需要 Codex 在线。笔记文件里，评论写在对应高亮下的 **评论** 一行。

**给整篇文档写评论。** 在 Tabgent 阅读视图（剪藏版或订阅条目）的标题下方、任意网页 / PDF / 书旁边侧边栏的页面抽屉里，以及资料库每篇文档下方，选择 **写全文评论**，写下你对整篇内容的看法：为什么保存、赞同什么、接下来想验证什么。评论支持 Markdown；⌘ Enter（Ctrl+Enter）保存，Esc 取消。不需要先高亮或剪藏：第一次写评论就会把这个网页存进笔记文件夹；还没保存的订阅条目会先保存。重新剪藏或退订它所在的订阅源，评论都不会丢。在侧边栏写到一半时页面变了，草稿会保留在那里，可以选 **保存到那篇** 或 **舍弃**；在资料库里打开另一篇的评论前，会先问你是否放弃未保存的修改。笔记文件里，评论是 **全文评论** 一节，位于元数据之后、高亮之前。

**给文档加标签。** 上面这三处也显示文档的标签。点 **＋标签** 后输入：会按使用次数提示你已经用过的标签，回车添加选中的标签，或新建一个。中文可以直接输入；不区分大小写（AI学习 和 ai学习 是同一个标签），显示保留你选定的写法；空格会变成连字符。点 × 或在空输入框里按 Backspace 可以移除标签。在资料库里点某个标签，只显示带这个标签的文档。**管理标签** 列出所有标签和各自的文档数：可以重命名；改成一个已有的标签名就是合并；也可以删除，删除只是把它从这些文档上移除，文档本身不删。每次操作执行前都会告诉你会影响几篇文档。资料库里还没有标签和评论的文档，鼠标移到它上面或用键盘移到它时，才显示 **＋标签** 和 **写全文评论**。笔记文件里，标签是 front matter 中的 `tags` 列表。

**在 Obsidian 里修改。** 评论和标签以笔记文件为准，所以也可以在 Obsidian 或其他编辑器里改：Tabgent 会显示你改过的内容；它写入时只改自己的评论小节和 `tags` 字段，笔记的其他内容原样保留。如果你在 Tabgent 里编辑评论时，这条评论在别处被改过，保存时那个版本会保留在笔记里，放在新评论上方。

**Codex 知道哪些上下文。** 每条消息都会告诉 Codex 你正在读哪篇文档、高亮的原文和位置、前后文、你对这条高亮写的评论，以及此前保存的关于它的讨论。你的评论会被标明是你自己的看法，方便 Codex 区分你的观点和作者的观点。Codex 会被要求围绕原文回答，区分作者观点和它自己的推断，并指出所引用的位置。你对整篇文档写的全文评论和它的标签也会一起发给 Codex，同样标明是你自己的看法。

**从上次停下的地方继续。** 每条高亮都有自己的对话。点击这段文字并选择 **查看讨论**，即可打开之前的问答并继续追问，重启 Chrome 之后也可以。侧边栏的 **Page chats（网页会话）** 也会列出本页的高亮：点击可以滚动到原文位置，也可以从这里打开讨论。

**针对整篇文档提问。** 不选中文字直接提问，就是围绕当前网页、PDF 或书的讨论。输入框旁的按钮显示这段对话保存到哪里：某条高亮、**页面笔记**，或 **不保存**。点开它可以打开或关闭 **保存到阅读笔记**。如果这篇文档已有笔记，默认会保存。关于高亮的对话始终会保存。

**笔记文件夹。** 笔记默认保存在 `~/Tabgent`，也可以在同一个菜单中改用其他文件夹；已保存的笔记不会被移动。文件夹的结构和 Readwise 导出的一样：每篇文档一个以标题命名的 Markdown 文件，按类别放在 `Articles/`（网页，包括从订阅保存的条目）、`Tweets/`（X 帖子）、`Videos/`、`Podcasts/`、`PDFs/`、`Books/`（EPUB 电子书）和 `Local Files/`（Mac 上的 Markdown、文本和 HTML 文件）中，有文档时才会出现对应的文件夹。每篇笔记先写标题、来源和元数据，然后列出你的高亮：引用的原文、下面的 **评论**，再是位置（章节标题、页码或章节）、时间，以及跳到原文和讨论的链接。你和 Codex 的讨论单独存放在 `Discussions/` 下的同名文件中，每条高亮一节，针对整篇文档的提问在 **关于整篇** 下；笔记和讨论之间可以互相跳转。剪藏的网页正文，以及从资料库打开的 PDF、EPUB（和高亮过的 Mac 上的 PDF）的文字，保存在 `Full Document Contents/` 中，每篇一个文件，按章或按页分节；图片、封面以及导入的 PDF 和电子书的副本在 `Attachments/` 中。Tabgent 自己的记录（用于恢复高亮的位置信息和文档目录）在隐藏的 `.tabgent/` 文件夹里。这些文件可以用 Obsidian、VS Code 或任意编辑器打开；你可以在这个文件夹里给笔记改名或移到别的子文件夹，Tabgent 仍然能找到它们。你在 Tabgent 标记的区块之外写下的内容会被保留；你改过标记区块时，Tabgent 更新这一块前会把你的版本作为你自己的文字保留下来。评论请在 Tabgent 中修改：直接在文件里改动的评论不会被读回。

**结合以前读过的内容提问。** 例如可以问：“我以前读过类似观点的内容吗？” Codex 会用一个无需批准的只读工具检索笔记文件夹，然后说明用到了哪篇文档、哪条高亮和哪个文件；找不到相关内容时也会如实说明。这个工具只读取 Tabgent 写入的笔记文件，不能修改它们。在允许执行命令时，Codex 也可能用命令行检索这个文件夹；这些命令遵循你选择的权限模式，不限于 Tabgent 的笔记文件。检索按关键词匹配，提问时使用笔记中出现过的词效果更好。

**按需读取更多原文。** 只有问题需要时，Codex 才会读取更多原文：例如你问到的 PDF 页面，从导入的 PDF 保存的页面文本中读取某一页（标签页关闭时也可以），从随书保存的章节文本中读取 EPUB 的某一章，或者读取你剪藏过的网页正文。

**剪藏网页。** 想保存网页正文时，右键点击工具栏中的 Tabgent 按钮或网页本身，选择 **剪藏此网页**；也可以按 ⌥⇧S（Alt+Shift+S，可在 `chrome://extensions/shortcuts` 中修改），或在侧边栏的阅读笔记菜单中选择。Tabgent 会按你看到的样子保存网页的正文（包括登录后才能看到的内容），作为全文存到 `Full Document Contents/` 中，并在这个网页的笔记里链接过去。导航、侧栏、广告、评论、推荐阅读和页脚会被去掉，链接、表格和代码会保留（网页用其他元素拼出来的表格也保留行和列），作者和嘉宾简介卡片也会保留，最多 50 张图片会保存到 `Attachments/Images/`，离线时 Obsidian 也能显示。如果网页上能看到的正文在提取时被漏掉，Tabgent 会按原位置补回，并在保存后告诉你。图注会紧跟在对应图片下方。作者、发布日期和封面图也会保存，包括只显示在网页上的（例如公众号文章和美团技术博客）。YouTube 视频会连同简介一起保存字幕，整理成文字稿（优先视频原语言的字幕，其次自动字幕并注明“自动生成”），按段落排列、每段链接到视频中的对应时间，有章节时按章节分节。播客单集会保存页面提供的文字稿。没有文字稿时（没有字幕、YouTube 要求登录或验证不是机器人、或没有返回字幕文本），Tabgent 会说明原因，只保存简介或节目笔记；在视频上打开字幕（CC）或展开「显示文字稿」后再剪藏一次可能会有帮助。如果只保存到了链接，Tabgent 也会如实提示，不显示成普通的剪藏成功，资料库里会标出这两种情况。网页上的高亮仍然属于这个网页。在 X 上，请先打开单条帖子或长文：Tabgent 会保存这条帖子，以及作者本人在页面上已加载的连续回复，不保存其他人的回复。网页正文很少时，可以改存整页；也可以先选中文字，再在阅读笔记菜单中选择 **仅剪藏选中内容**。再次剪藏同一个网页时，会先询问是否替换；如果你改过它的全文，你的版本会另存为 `<名称>（编辑版 <时间>）.md`。Codex 可以用阅读笔记工具检索和阅读剪藏的正文；你询问这个网页时，Codex 也会知道它的位置。

**阅读剪藏版。** 剪藏完成后在提示中选择 **打开剪藏版**，或在侧边栏的阅读笔记菜单中选择它，也可以在资料库中点击这个网页。剪藏版在 Tabgent 的阅读视图中离线打开：干净的版面、封面和保存的图片、作者和发布日期、可调整的字号，并记住阅读位置。在这里可以像在网页上一样高亮、**评论**和 **询问 AI**：它们属于同一个网页，所以也会显示在原网页上和它的讨论中。**原网页** 打开实时网页，**删除剪藏** 只删除剪藏版，保留你的高亮。网页中的脚本、表单和远程内容在阅读视图中不会运行或加载。

**资料库。** 右键点击工具栏中的 Tabgent 按钮，选择 **打开资料库**；也可以在侧边栏的阅读笔记菜单中选择 **打开资料库**，在当前网页旁边打开它。资料库按最近更新排序，列出笔记文件夹中的所有文档：网页、这台电脑上的文件、在线 PDF、导入的 PDF 和 EPUB 电子书，并显示类别、作者或网站、高亮数量和最近更新时间。点击即可重新打开：网页打开原地址（剪藏过的网页在 Tabgent 的阅读视图中打开，旁边有 **原网页** 链接），Markdown、文本和 HTML 文件从它在 Mac 上的位置打开，在线 PDF 在 Tabgent 的 PDF 阅读器中打开，导入的 PDF 和电子书从笔记文件夹中的副本打开。

**Mac 上的 PDF。** 在资料库中选择或拖入 PDF 文件（不超过 100 MB）。Tabgent 会把它复制到笔记文件夹（可在其他应用中打开的副本在 `Attachments/PDFs/`），并在 PDF 阅读器中打开；高亮、评论、**询问 AI** 和保存的讨论都与在线 PDF 相同。之后无需原文件即可从资料库重新打开；再次打开同一个文件会使用已有的副本。在 macOS 上，每一页的文字会通过 PDFKit 保存到它的全文中，即使关闭了标签页，Codex 也能检索和阅读这篇论文。扫描页没有文字；受密码保护的 PDF 在阅读器中输入密码后即可打开，但不会保存页面文字。PDF 以其标题命名，没有标题时使用文件名。

**在 Chrome 中打开的文件。** 在 Mac 上双击 PDF、Markdown、文本或 HTML 文件，照常在 Chrome 中阅读，无需导入。选中文字即可 **高亮**、**评论** 或 **询问 AI**，也可以针对整个文件提问，和在网页上一样。PDF 会在同一个标签页中切换到 Tabgent 的 PDF 阅读器（地址栏显示 Tabgent 的地址，与在线 PDF 相同）；点击 **用 Chrome 阅读器打开** 可以让这个标签页改回 Chrome 自带的阅读器。Markdown、文本和 HTML 文件保持 Chrome 的显示方式，Markdown 以纯文本显示。

- **只需授权一次。** Chrome 只有在你为扩展打开 `chrome://extensions` 中的“允许访问文件网址”后，才允许它读取文件。未开启时第一次打开文件，Tabgent 会打开一个说明页面，并提供直达 Tabgent 设置的按钮；在这类文件上，侧边栏也会显示提醒。开启后，已经打开的文件无需刷新即可使用。
- **PDF 的笔记跟随内容。** PDF 以文件内容的 SHA-256 命名，与资料库导入相同。第一次高亮或保存讨论时，它会连同页面文字复制到笔记文件夹；因此移动或重命名文件后笔记仍在，资料库可以重新打开它，导入同一个文件也共用这些笔记。只打开 PDF 不会保存任何内容。超过 100 MB 的 PDF 会保留笔记，但不保存副本。
- **文本文件的笔记跟随路径。** Markdown、文本和 HTML 文件会随着编辑而改变，所以它们的笔记属于 `file://` 地址，和网页的笔记一样；编辑后，高亮会像网页一样重新找到原文。移动或重命名文件后，笔记仍留在原来的地址下。
- **Codex 能做什么。** Codex 可以读取你打开的文件（PDF 按页读取），并把文件路径视为页面地址。它不能在文件中点击或输入，也不能自行打开文件；文件夹列表（`file:///…/`）不会被当作文档。

**订阅。** 资料库的 **订阅** 页可以订阅 RSS、Atom 和 JSON Feed。填入订阅源地址，或者填网站地址来查找它声明的订阅源，确认预览后选择 **订阅**；**导入 OPML** 可以导入从其他阅读器导出的订阅，文件夹会成为分类，**导出 OPML** 可以保存你的订阅。Chrome 运行时，Tabgent 大约每小时检查一次每个订阅（按订阅源的要求，从每 30 分钟到每天一次），请求不带 Cookie；**全部刷新** 立即检查，**暂停所有订阅** 停止定时检查。列表显示每个订阅的未读数，以及上次更新的时间或失败原因，并提供 **重试**；**设置** 可以改名、归入分类、设置更新间隔、暂停或退订。新订阅先放入最近的 20 条。

**阅读和整理条目。** 订阅页按 **未读**、**稍后读**、**归档** 或 **全部** 列出条目，每篇文章一行（同一篇出现在两个订阅里只显示一次，标明来自哪两个）。点击条目会在 Tabgent 的阅读视图中打开：订阅源里的正文经过清理，并显示图片；订阅源只给摘要时，Tabgent 会从文章网页加载全文（每个订阅可以设置：**订阅源只给摘要时**、**总是** 或 **从不**，需要时点 **加载全文**）。打开即标为已读。在列表中，**标为已读**/**标为未读**、**稍后读**、**归档** 和 **原网页** 作用于一行，**全部标为已读** 作用于未读列表；也可以用快捷键：j、k 上下移动，Enter 打开，m 已读，l 稍后读，e 归档，v 原网页。**原网页** 打开去掉跟踪参数之后的地址，所以在原网页上做的笔记也属于这一条。

**保存条目。** 在阅读视图里可以像在网页上一样高亮、评论和向 Codex 提问：第一次高亮或提问，或者点 **保存到资料库**，都会把这一条像剪藏的网页一样连同正文和图片保存到笔记文件夹。在此之前，条目只存在笔记文件夹里的一个文件中（`.tabgent/feeds.db`），订阅不会在 Obsidian 里多出文件夹。稍后读和归档也适用于已保存的条目和剪藏的网页。

**EPUB 电子书。** 在资料库中选择或拖入 EPUB 文件。这本书会复制到笔记文件夹，每一章的文字另存为一个 Markdown 文件，再次打开时回到上次的位置。阅读器提供目录和高亮列表、字号调整，以及分页或滚动阅读。书中的脚本，以及远程图片、字体和样式都会被拦截。

**限制。** 网页高亮只支持页面本身，不支持页面内嵌的框架；安装或更新 Tabgent 之前已经打开的标签页需要刷新。PDF 高亮需要使用 Tabgent 的 PDF 阅读器，它打开在线（HTTP 或 HTTPS）PDF、从 Mac 打开的 PDF 和从资料库打开的 PDF，且文字需要可以选中。从 Mac 打开的文件需要开启“允许访问文件网址”；未开启时它们照常在 Chrome 中打开，但无法使用 Tabgent。如果 Chrome 未运行，双击的 PDF 会先短暂显示 Chrome 自带的阅读器，再切换到 Tabgent 的阅读器。在线 PDF 和 Mac 上同一文件的副本是两篇独立的文档，各自保存笔记。打开 Mac 上的 PDF 需要连接器；页面文字需要 macOS PDFKit，扫描页不会进行 OCR 识别。导入的文件保留在保存时的笔记文件夹中：改用其他文件夹后，需要在资料库中重新选择文件。固定版式的 EPUB 会保存高亮，但不会在书中显示。剪藏只读取页面本身，不包括内嵌框架和网页组件内部的内容。SVG 图片、超过 5 MB 的图片、超出每页 50 张或 30 MB 的图片，以及下载失败的图片，会保留网上的链接。如果找不到某条高亮对应的原文，Tabgent 会保留笔记并标记为未找到，而不会错误地标注其他文字；目前还不能重新定位。订阅只在 Chrome 运行时检查：停了一段时间后，比订阅源仍保留的条目更早的内容会错过。暂不支持需要登录的订阅源。全文是在不运行网页脚本的情况下读取的，所以靠脚本生成内容的网页、验证页和 Cookie 同意弹窗会退回到订阅源的摘要：请打开原网页，在那里剪藏。存储和发送的数据详见[隐私与权限](privacy.md)。

## 把相关材料一起交给助手

- **针对原文提问：** 在网页选中文字，再到侧边栏提问。也可以右键点击选中的文字，使用 **Quote in Agent（引用到助手）** 把它带入对话。
- **确认正在讨论哪个页面：** 输入框旁的标签页图标显示下一条消息对应的页面。如果多个标签页共用一个会话，可以在发送前点击查看详情。
- **附上自己的材料：** 点击附件按钮，粘贴文件或图片，或直接拖入输入框。图片支持预览；PDF、DOCX 和文本附件可以结合网页一起阅读。每条消息最多附加 10 个文件，每个不超过 10 MiB。扫描版 PDF 可能没有可读取的文字。
- **直接使用网站：** Tabgent 可以读取网页、查看截图、点击控件、填写表单、选择选项、滚动和切换页面。鼠标操作时会显示虚拟指针。不同网站的支持情况可能不同。

## 让网页和会话保持关联

打开 **Page chats（网页会话）**，查看与当前网址关联的对话。发送消息时，该网页才会与会话建立关联；仅仅切换网页不会建立关联。同一个会话里聊过多个网址，就能从这些网页各自的历史列表找到它。列表不显示空会话。

从链接打开新标签页并产生关联会话时，原会话会记录新会话，新会话也会显示自己的来处。点击会话名称即可切换到对应标签页。这样能顺着网页找回之前的工作，但不会把原会话的全部内容复制进新会话。浏览器重启后，可能无法自动回到原来的标签页。

点击 Agent 顶部的 **+**，在当前页面开始新会话。需要更多阅读空间时，点击展开到新页面的按钮，在完整的 Agent 页面继续当前对话。

## 任务进行中也能随时调整

- **查看进度：** 展开活动记录，查看执行步骤和工具活动。任务包含计划时，对话中也会展示计划进度。
- **排队补充：** 助手工作时可以继续发送要求；待发送消息可以编辑或删除。
- **立即调整：** 使用 **Steer** 把要求交给当前任务，不必等下一轮。
- **停止：** 点击停止按钮。已经完成的操作不会因此撤销。
- **先梳理计划：** 输入 `/plan` 切换到计划模式，再描述任务。再次使用可退出计划模式。
- **围绕目标继续工作：** 输入 `/goal` 设置目标和可选的 token 用量上限。目标控件支持查看进度、修改、暂停、恢复或清除。此功能需要你的 Codex 版本支持。

## 按你的习惯使用

**模型与思考强度。** 点击输入框旁的模型选择器，在同一个菜单中选择模型及思考强度。可用选项来自你的 Codex 配置。

**批准方式与浏览器范围。** 可以选择 **Ask for approval（请求批准）**、**Approve for me（代为审批）** 或 **Full access（完全访问）**。浏览器操作范围另行选择 **Current window（当前窗口）** 或 **All windows（所有窗口）**；这项范围设置不限制 Codex 的其他工具和已连接服务。各项设置的边界详见[隐私与权限](privacy.md)。

**技能和其他工具。** 输入 `/skills` 浏览及管理可用技能，或输入 `$` 为消息选择技能。会话也可以使用 Codex 原生工具（包括网页搜索），以及已配置的应用或 MCP 集成。具体取决于 Codex 版本、模型、权限和配置；Tabgent 不会自动替你连接新的服务。

**保留结果。** 点击回答下方的 **Copy（复制）**，或输入 `/export`，将会话里的用户消息和助手回答下载为 Markdown。导出内容是文本，不包含附件备份或浏览器录像。输入 `/rename` 可以给会话起一个容易辨认的名字。回答支持展示表格、代码和数学公式。

**管理较长的对话。** `/status` 可查看模型及可用的上下文用量信息；`/compact` 会请 Codex 压缩对话上下文，减少继续聊天时占用的空间。
